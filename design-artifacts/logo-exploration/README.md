# Aether Logo Exploration

These are hand-built SVG logo concepts for Aether. The goal is to avoid generative-logo noise and test simple silhouettes that can become real app assets.

## Concepts

- `aether-mark-01-ribbon-core.svg` - closest to the current rounded A, with a clearer internal core.
- `aether-mark-02-aperture.svg` - sharpest, most scalable mark.
- `aether-mark-03-orbit.svg` - adds a second-brain/orbit cue.
- `aether-mark-04-gate.svg` - private-core direction.
- `aether-mark-05-monoline.svg` - simplest monochrome-friendly option.
- `aether-mark-06-cutout.svg` - bolder icon-block option with negative-space center.

Open `contact-sheet.html` to compare them.
